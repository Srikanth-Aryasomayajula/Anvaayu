# Anvaayu website

A responsive, static multi-page website for Anvaayu's Identity & Access Management services.

## Pages
- `index.html` — homepage and service overview
- `services.html` — detailed IAM services
- `team.html` — team profiles
- `contact.html` — contact information and email-based enquiry form

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension for a local preview.

## Publish on GitHub Pages
1. Unzip the project.
2. Copy the contents of this folder into the root of `Srikanth-Aryasomayajula/Anvaayu` (replace the test `index.html` and add the other files/folders).
3. Commit and push to the branch configured for GitHub Pages (commonly `main`).
4. In GitHub, open **Settings → Pages** and confirm the source branch and root folder.
5. Visit `https://srikanth-aryasomayajula.github.io/Anvaayu/` after the deployment finishes.
